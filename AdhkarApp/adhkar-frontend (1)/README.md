# أذكاري | Adhkar Frontend

فرونت-إند بسيط وأنيق لموقع الأذكار، مبني بـ React + Vite، ومتصل بالكامل بالـ Django REST backend الموجود (Djoser + SimpleJWT).

## التشغيل محليًا

```bash
npm install
cp .env.example .env   # ثم عدّل VITE_API_URL لو الباك-إند مش على 127.0.0.1:8000
npm run dev
```

## البناء للإنتاج

```bash
npm run build
```

الناتج في مجلد `dist/`.

## متغيرات البيئة

| المتغير | الوصف | الافتراضي |
|---|---|---|
| `VITE_API_URL` | رابط الباك-إند (بدون `/` في النهاية) | `http://127.0.0.1:8000` |

## النشر على Vercel

1. ارفع هذا المجلد إلى مستودع GitHub منفصل (أو استخدم Vercel Drop).
2. من Vercel: Import Project → اختر المستودع.
3. Framework Preset: **Vite** (يُكتشف تلقائيًا).
4. أضف متغير البيئة `VITE_API_URL` في إعدادات المشروع على Vercel، وضع فيه رابط الباك-إند المنشور فعليًا (وليس `127.0.0.1`).
5. Deploy.

## ⚠️ ملاحظات مهمة عن الباك-إند

- **CORS**: تم تفعيل `django-cors-headers` في `settings.py` (كانت مضافة في `requirements.txt` لكن غير مفعّلة). بدون هذا التعديل، أي طلب من هذا الفرونت-إند كان سيُرفض من المتصفح.
- **تصنيف الأذكار حسب القسم**: الـ `CategorySerializer` في الباك-إند لا يُرجع `id` للقسم، لذلك الفلترة بين الأقسام والأذكار تتم عبر `?search=اسم_القسم` (باستخدام `SearchFilter` الموجود فعليًا على `category__name`)، وليس عبر `category_id` مباشر. هذا حل بديل يعمل، لكنه غير دقيق 100% إذا تشابهت أسماء الأقسام مع عناوين أذكار أخرى. لتحسين هذا لاحقًا: أضف `id` إلى `fields` في `CategorySerializer` وأضف query param فلترة دقيق في `ListCreateAdhkar` (مثال: `filterset_fields = ['category']` مع `django-filter`).
- **الصور (Rewards)**: تظهر روابط الصور الكاملة تلقائيًا من DRF بناءً على الطلب، لكن تخزين/تقديم ملفات الميديا في وضع `DEBUG=False` (بيئة إنتاج) يحتاج إعداد تخزين مناسب (مثل خدمة S3 أو ما شابه) — إعداد `static()` الحالي يعمل فقط أثناء `DEBUG=True`.

## هيكل المشروع

```
src/
  api/         # طبقة الاتصال بالـ API (axios)
  components/  # مكونات قابلة لإعادة الاستخدام
  context/     # AuthContext لإدارة تسجيل الدخول والـ JWT
  hooks/       # useAuth
  pages/       # صفحات التطبيق
  styles/      # التصميم العام (ألوان، بطاقات، نماذج)
```
